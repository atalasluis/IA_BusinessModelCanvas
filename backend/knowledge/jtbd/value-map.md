# Value Map

## Propósito

El Value Map organiza cómo una solución pretende crear valor para un
Customer Profile. Se estructura alrededor de productos y servicios, pain
relievers y gain creators.

## Products and Services

Son los productos y servicios que la empresa ofrece para ayudar al
cliente.

## Pain Relievers

Describen cómo la solución reduce o elimina determinados dolores del
cliente.

Un pain reliever debe relacionarse con un Pain concreto y no simplemente
enumerar una característica.

## Gain Creators

Describen cómo la solución ayuda a producir beneficios o resultados
deseados.

## Encaje

El objetivo es encontrar correspondencia entre:

-   Jobs ↔ productos y servicios.
-   Pains ↔ pain relievers.
-   Gains ↔ gain creators.

No todos los elementos necesitan tener correspondencia. La prioridad es
atender los problemas y beneficios relevantes.

## Preguntas

-   ¿Qué Job atendemos?
-   ¿Qué Pain reducimos?
-   ¿Qué Gain facilitamos?
-   ¿Qué evidencia existe?
-   ¿Qué elementos son hipótesis?
-   ¿Qué aspectos del Value Map no tienen un Customer Profile claro?

## Relación con Business Model Canvas

El Value Map puede aportar información para formular la propuesta de
valor del BMC y revisar si el modelo responde a un segmento específico.

## Uso en IA_BusinessModelCanvas

La IA debe explicar el encaje entre Customer Profile y Value Map,
identificar vacíos y proponer hipótesis para validar. No debe afirmar
que existe product-market fit solamente porque haya correspondencia
conceptual.
