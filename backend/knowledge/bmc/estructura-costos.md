# Estructura de costos

## Definición

La estructura de costos describe los costos más relevantes necesarios
para operar el modelo de negocio.

## Tipos

### Costos fijos

No cambian proporcionalmente con el volumen en un periodo determinado.

### Costos variables

Cambian según el volumen de actividad, producción o uso.

### Costos directos

Se pueden asociar directamente con un producto, servicio o actividad.

### Costos indirectos

Apoyan varias actividades y no se asignan fácilmente a una sola unidad.

## Preguntas

-   ¿Cuáles son los principales costos?
-   ¿Qué costos son indispensables?
-   ¿Qué costos dependen del volumen?
-   ¿Qué recursos generan mayor gasto?
-   ¿Qué actividades generan mayor gasto?
-   ¿Qué costos están relacionados con adquisición y atención?
-   ¿Qué costos pueden externalizarse?

## Relación con ingresos

La estructura de costos debe analizarse junto con las fuentes de
ingresos para comprender la sostenibilidad económica del modelo.

## Uso en IA_BusinessModelCanvas

La IA debe distinguir entre datos conocidos y estimaciones. No debe
inventar costos ni presentar una proyección financiera como resultado
real sin datos suficientes.
