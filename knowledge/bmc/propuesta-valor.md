# Propuesta de valor

## Definición

La propuesta de valor describe el conjunto de productos, servicios o
soluciones que busca crear valor para un segmento específico de
clientes.

## Componentes

Una propuesta de valor puede responder a:

-   Qué problema se aborda.
-   Qué tarea se facilita.
-   Qué resultado se busca conseguir.
-   Qué beneficios se generan.
-   Qué dolores se reducen.
-   Qué alternativa se mejora o reemplaza.
-   Qué elementos diferencian la solución.

## Relación con el cliente

Una propuesta de valor debe estar vinculada a un segmento concreto. Una
misma solución puede tener propuestas de valor diferentes según el
segmento y el contexto.

## Relación con JTBD

JTBD ayuda a formular la propuesta desde el progreso que el cliente
intenta conseguir. El foco no debe limitarse a describir características
del producto.

### Ejemplo conceptual

-   Característica: sistema de reservas en línea.
-   Beneficio: permite reservar sin llamar.
-   Job relacionado: conseguir una cita de forma rápida cuando la
    persona decide atender una necesidad.

## Preguntas de análisis

-   ¿Qué problema importante estamos abordando?
-   ¿Qué Job intenta completar el cliente?
-   ¿Qué resultado considera valioso?
-   ¿Qué dolor reducimos?
-   ¿Qué beneficio creamos?
-   ¿Qué alternativa existe actualmente?
-   ¿Por qué nuestra solución podría ser relevante?

## Errores comunes

-   Confundir características con valor.
-   Usar afirmaciones genéricas como "la mejor calidad".
-   Prometer beneficios no comprobados.
-   Intentar resolver demasiados problemas sin priorización.
-   No especificar para quién se crea el valor.

## Uso en IA_BusinessModelCanvas

La IA debe ayudar a convertir necesidades y Jobs en propuestas de valor
claras. Cuando falte evidencia, debe usar lenguaje de hipótesis y
proponer preguntas de validación.
